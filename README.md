# Nachbereitungsauftrag-1

## Theoretische Vertifeung
HTML ist die Grundstruktur einer Webseite. CSS ist für das visuelle Styling zuständig. JavaScript ist für die Logik
und Funktionalität zuständig.
Typescript baut auf JavaScript auf ist aber noch typisiert sprich die Typen können angegeben werden.
Bei let darf ich den Wert später ändern. Bei const darf ich der Variable keinen neuen Wert zuweisen.
Ein commit speichert Änderungen als dokumentierten Zwischenstand in meinem lokalen Git-Repository. Damit kann ich später nachvollziehen, was ich verändert habe.
Ein push überträgt meine lokalen Commits auf ein Repository.
Mit einer Versionsverwaltung wie Git kann ich Änderungen an meinem Code nachvollziehen und frühere Zustände wiederherstellen.
